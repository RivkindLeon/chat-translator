# Hebrew Bridge

Переводчик ивритских чатов WhatsApp. Читает выбранные группы, переводит
сообщения на русский и присылает их в Telegram — каждую группу в свой чат.

Работает как плагин OpenClaw на собственном сервере. Наружу уходят только
запросы к модели: сама переписка, ключи и журналы остаются на сервере.

---

## Что умеет

**Текст** — сообщения копятся пачками и переводятся одним запросом: так дешевле,
меньше уведомлений и модель лучше понимает, кто кому отвечает.

**Голосовые** — расшифровываются и переводятся наравне с текстом.

**Фотографии с текстом** — объявления, расписания, меню. Текст снимается с
изображения и переводится с сохранением структуры: таблица остаётся таблицей,
сгруппированной по дням, а не превращается в сплошную строку.

**Фото без текста** — отмечаются строкой «📷 изображение», модель не вызывается.

## Чего не делает намеренно

В WhatsApp плагин **ничего не пишет** — ни в группы, ни в личные чаты. Любая
попытка отправки отменяется и записывается в журнал.

Ассистент **не запускается** на сообщениях читаемых групп: их видит только
переводчик. Поэтому подброшенная в чат инструкция не может ничего выполнить
на сервере, а токены не тратятся на чужую переписку.

---

## Маршруты

Каждая группа-источник привязана к своему чату доставки: у неё свой накопитель,
свой контекст и свой словарь имён, поэтому переписки не смешиваются. Список
маршрутов живёт в настройках, в репозитории его нет.

## Во что обходится

Практически ни во что. Перевод, расшифровка голоса и распознавание картинок
идут через подписку ChatGPT Plus: токены по ней не тарифицируются, расходуется
только квота. После десятков переводов она показывает полные 100%.

Платные модели остались запасным вариантом: если квота кончится, перевод не
остановится, а продолжится через них за считанные центы.

За всё время работы потрачено меньше одной десятой цента — на самый первый
перевод, до перехода на подписку.

## Команды

Все запускаются на сервере, в каталоге плагина
`~/.openclaw/extensions/hebrew-bridge/`.

```bash
node groups.mjs        # какие группы видел сервер, с обрывками сообщений
node add-group.mjs <JID> "Название" [chatId] [threadId]
node limits.mjs        # остаток квоты подписки и текущие модели
node report.mjs        # расходы за месяц (2026-09 · all · --days)
node test.mjs          # 44 проверки логики
```

Журнал: `~/.openclaw/hebrew-bridge/logs/ГГГГ-ММ-ДД.log`
Учёт вызовов: `~/.openclaw/hebrew-bridge/usage.jsonl`

## Как подключить новую группу

1. `node groups.mjs` — найти группу по обрывкам сообщений.
   WhatsApp не сообщает названия групп, только идентификаторы,
   поэтому опознавать приходится по содержимому.
2. Создать чат в Telegram, добавить туда бота, написать с упоминанием бота.
3. Найти идентификатор чата:
   `grep "skipping group message" /tmp/openclaw/openclaw-*.log`
4. `node add-group.mjs <JID> "Название" <chatId>` — добавит и перезапустит.

Если группу подключили задним числом, её недавние сообщения можно догнать:
временно задать в настройках `replay: {jid, minutes}`, перезапустить,
затем убрать. Глубина ограничена журналом шлюза — он живёт двое суток.

## Настройки

Лежат в `~/.openclaw/openclaw.json`, раздел
`plugins.entries.hebrew-bridge.config`.

| Параметр | Смысл |
|---|---|
| `routes` | список маршрутов: `{jid, name, chatId, threadId?, glossary?, ...}` |
| `debounceMs` | пауза тишины перед отправкой пачки, по умолчанию 20 секунд |
| `maxWaitMs` | предел ожидания, если в чате не умолкают |
| `maxBatch` | максимум сообщений в пачке |
| `contextSize` | сколько прошлых сообщений идёт в контекст |
| `glossary` | как писать имена и термины; можно задать общий и свой у маршрута |
| `imageProvider` / `imageModel` | чем читать текст с картинок |
| `quotaThreshold` | при каком остатке квоты предупредить (в процентах) |
| `alertChatId` | куда слать технические предупреждения |
| `logTexts` | сохранять тексты для оценки качества — только на время отладки |

Любые настройки маршрута перекрывают общие: у болтливого чата может быть своя
задержка, у рабочего — свой словарь.

## Что дальше

Сейчас плагин написан под один случай: WhatsApp на входе, Telegram на выходе,
русский язык в подсказках модели. Чтобы им мог пользоваться кто-то ещё, нужно
снять эти допущения:

1. **Любой источник** — слой «источник» вместо жёсткой привязки к WhatsApp.
   Самое существенное изменение, задаёт форму остальному.
2. **Любой получатель** — доставка уже сведена к одной функции, вынести за интерфейс.
3. **Любая пара языков** — подсказки модели переписать с подстановкой языков.
4. **Настройки вместо зашитых значений** — часовой пояс, подписи вложений, формат.
5. **Постоянный реестр групп** — сейчас опознание зависит от журнала, живущего двое суток.
6. **Своя модель на маршрут** — сейчас модель берётся от основного агента.
